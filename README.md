# Flutter Examen 2

Aplicación móvil desarrollada utilizando Flutter para el frontend, FastAPI para el backend y SQLite como base de datos local.

## Tecnologías utilizadas

* Flutter
* Dart
* FastAPI
* Python
* SQLite
* HTTP REST API

## Descripción

El proyecto consiste en una aplicación móvil que consume información desde una API desarrollada con FastAPI y muestra los datos en una interfaz construida con Flutter.

La información es almacenada y gestionada mediante SQLite, permitiendo realizar consultas de forma eficiente.

Este proyecto fue realizado como parte de una evaluación académica. Durante el desarrollo utilicé herramientas de inteligencia artificial como apoyo para aprender conceptos relacionados con FastAPI, resolver dudas técnicas y comprender mejor la integración entre el backend y la aplicación móvil.

## Funcionalidades

* Consumo de API REST
* Obtención de datos desde el backend
* Visualización de información en la aplicación móvil
* Manejo de modelos de datos
* Integración entre frontend y backend

## Lo que aprendí

Durante este proyecto aprendí a:

* Crear APIs con FastAPI
* Consumir APIs REST desde Flutter
* Modelar datos en Dart
* Integrar frontend y backend
* Trabajar con bases de datos SQLite

## Proyecto académico

Este proyecto fue desarrollado como parte de la materia de Programación Avanzada de Apps de la Universidad San Francisco de Quito (USFQ).

## Ejecución

### Backend

```bash
pip install -r requirements.txt
uvicorn main:app --reload

run pub get
```

### Frontend

```bash
flutter pub get
flutter run
```
